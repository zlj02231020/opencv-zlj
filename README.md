# opencv-zlj

RoboMaster 视觉组选拔 · OpenCV 考核作业（10 题）

每题一个目录 `q01` … `q10`，目录里有三样东西：

- `main.cpp` —— 程序本身，开头有大段注释说明思路和踩过的坑
- `输出.txt` —— 在这台机器上实际运行后控制台打印的完整结果（数字答案就在这里）
- `qNN_result.png` —— 运行后写出的结果图，标框、标号都画在上面

测试图和参考答案图都在 `images/`。

## 编译

    make

等价于：

    g++ -std=c++17 -O2 q03/main.cpp -o q03/a.out $(pkg-config --cflags --libs opencv4)

## 运行

    cd q06 && ./a.out

也可以带参数指定输入输出：

    ./a.out ../images/q06_test.png q06_result.png

不给参数时默认读 `images/qNN_test.png`，结果写当前目录的 `qNN_result.png`。
每个 `qNN/` 下的 `images` 是指向 `../images` 的软链接，所以在题目目录里直接运行也能找到测试图。

## 各题做法与实测结果

下表"实测结果"一列，都能在对应目录的 `输出.txt` 里逐字找到。

| 题 | 用到的东西 | 实测结果 |
|----|-----------|---------|
| 01 多形状分类计数 | 饱和度切前景；按色相分层拆开互相压盖的物块；分类只看几何量（圆度 4πA/P²、多边形顶点数、填充率），被压盖的用凸包补缺口再判 | 圆 8、矩形 6、三角形 8 |
| 02 硬币检测与面值 | HoughCircles 定位，距离变换在圆心附近取峰值精修半径，半径做 k-means 自动分三档 | 18 枚：1元 5（r≈50）、5角 6（r≈38）、1角 7（r≈27），合计 8.7 元 |
| 03 表面缺陷检测 | 大核中值滤波估背景，残差二值化，按长宽比 / 面积 / 灰度极性分三类 | 划痕 3、暗斑 2、亮点 1，共 6 个 |
| 04 直线检测与角度 | HoughLinesP 检直线段，按过中心点的方向聚类成射线，atan2 求角度；蓝色字母用字形模板匹配认出来，再按方向配给射线 | 5 条射线：A 0°、B 141°、C 180°、D 321°、E 225° |
| 05 轮廓匹配与瑕疵 | 标准齿轮轮廓当模板，matchShapes 量化相似度，极坐标下找缺齿缺口 | 标准件 12 齿；Sample A 9 齿缺 1 处、Sample B 10 齿缺 1 处，距离 0.0031 / 0.0066 |
| 06 颗粒计数与面积 | HSV 掩码 + 距离变换；用面积/(π·dmax²) 判断一个连通域里有几个颗粒，k-means 布种子，分水岭切开粘连 | 29 个颗粒，面积 441–5417 px²，总面积 85691 px² |
| 07 焊缝裂纹 | 中值背景残差 + 闭运算接断口（不能开运算，会切断细裂纹），Zhang-Suen 细化骨架，两次 BFS 求最长路径 | 3 条裂纹：300 / 135 / 85 px（首尾直线 197 / 97 / 59） |
| 08 颜色区域面积 | HSV 里卡色相，红色跨 0/180 两端要两段 inRange 取或，逐色统计像素与占比 | 蓝 6.84%、黄 4.60%、紫 4.21%、红 0.71%、绿 0.15% |
| 09 棋盘格角点与标定 | 用饱和度和明度把彩色干扰物刷白，findChessboardCorners 检内角点（13×9 方格减一 = 12×8），cornerSubPix 亚像素精化 | 96 个角点，格宽 50.00 px，10.00 px/mm |
| 10 轨迹追踪分析 | 颜色分离滤掉文字标签，沿主轴分箱得到单值曲线，一/二次拟合比残差判运动类型；起点/终点按图上自带的 start/end 小字定向 | A 抛物线 738 px、B 抛物线（加速下落）782 px、C 正弦 725 px（振幅 79、峰谷落差 157、周期 299） |

几处和参考答案不完全一致的地方，代码注释里都写了实测数据。

第二题参考答案图上的 `Total:17` 是硬币枚数，不是金额。实测是 18 枚、合计 8.7 元：参考答案少算了
左上角叠在一起的两枚（圆心距 63 px，小于两半径之和 78 px），霍夫把它们并成了一个圆。按它的
5+6+6 枚算金额是 8.6 元，和 8.7 差的就是少算的那枚 1 角。

第四题参考答案图上的 `P-B: 50 deg` 一类数字和图上画出来的线对不上。按像素实测，∠APB = 141°、
∠APC = 180°、∠APD = 39°、∠APE = 135°，只有 APC 的 180° 和参考答案相符；参考答案里的 50°、120°、
45°，在这张图的几何里用任何度量方式都得不到。

第六题参考答案按 24 个颗粒算，这里分水岭拆出来是 29 个（题目给的范围是 24–30）。

第九题用 `Size(8,12)` 也能检出角点（棋盘格转置一下还是棋盘格），但角点顺序是列优先、从下往上，
连出来的彩线是竖的，看着就像图片倒了；换成 `Size(12,8)` 后是从左上到右下一行一行连，和参考
答案的观感一致，八个数字（96 个角点、50.00 px、10.00 px/mm）完全相同。

第十题参考答案说红色轨迹最长，实测蓝色 782 px、红色 738 px，蓝色长 43 px，两条几乎等长；红色
是竖直落差最大的那条（552 px）。

## 关于部分原图上的 "?"

`images/` 里有四张图本身就带问号，是出题方生成图片时用 OpenCV 的 `putText` 写中文导致的
（Hershey 字体只有 ASCII 字形，汉字会画成 `?`）。这四张图与 PDF 内嵌的原始图片逐像素一致，
本仓库没有修改过：

- `q02_test.png`、`q02_ref.png` —— 硬币面上的 `1???`、`5???`
- `q04_ref.png` —— 角度标注 `P-B: 50??`
- `q10_ref.png` —— 标题里的中文

本仓库自己的程序画到图上的标注一律用英文（`1 jiao`、`parabola`、`141 deg`），控制台输出保留中文。
所以 q02 结果图里硬币面上仍有问号，那是原图带来的，硬币下面那排英文标签才是程序画的。
